# ContactsManager

## Description
Application Java qui permet de gérer une liste de contacts.
L'utilisateur peut ajouter des contacts, rechercher un contact
par son nom et afficher son numéro de téléphone.

## Technologies
- Java 21
- IntelliJ IDEA

## Structure du projet
- `Contact.java` : Classe représentant un contact
- `ContactsManager.java` : Classe gérant la liste des contacts
- `Main.java` : Programme principal

## Fonctionnalités
- Ajouter un contact (nom + numéro de téléphone)
- Rechercher un contact par nom
- Saisir le nom à rechercher au clavier
- Afficher le numéro de téléphone du contact trouvé
- Afficher le nombre total de contacts ajoutés

## Exemple de résultat
Entrez le nom à rechercher : tossah fafa
Contact trouvé !
Nom       : tossah fafa
Téléphone : 0717306789
